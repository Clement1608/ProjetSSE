# ProjetSSE

Le code se trouve dans le fichier Projet SSE. Il contient les différents scripts ainsi que les fichier txt, nécessaire pour le fonctionnement du projet.

A l'intérieur vous trouverez les différents scripts individuels ainsi que les fonctions permettant la création de rapport, l'énumération des poste / correctifs / Inventaires complet...

Pour plus de détails spécifique sur les programmes nous vous invitons à lire le rapport rendu sur Moodle, les scripts ainsi que leurs fonctionnement sont détaillés afin de mieux les assimiler. La vidéo explicative permet aussi de comprendre ce que font les différents programmes, avec le résultat en temps réel.
